# Experiments

Scripts written to answer a question about Ensign before deciding whether to build something.

Nothing in this folder is part of Ensign:

- It isn't installed with the `ensign-scan` package.
- The test suite doesn't run it.
- It can change or be removed at any time.

Each subfolder is one line of investigation, with a README that says what was asked, how to run the scripts, and where the results are written up.

|---|---|---|
